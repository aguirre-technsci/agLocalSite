# Checklist visual: paletas e painel de configurações

As paletas passam numa régua de contraste numérica (`tests/test_paletas.py`), mas ninguém viu a interface de verdade nelas. Este roteiro leva uns 15 minutos.

**Como trocar de paleta:** com o `start` aberto, clique em **⚙ Configurar → Aparência**, escolha a paleta e o modo e olhe a página (a prévia é ao vivo; **Fechar** desfaz). Para o modo, use também o botão Claro/Escuro do menu.

**Em cada combinação, olhe estas 6 áreas** e marque `x` se estiver boa. Anote em "Problemas" qualquer coisa que destoe (texto difícil de ler, borda que some, cor que briga).

| Área | O que conferir |
|---|---|
| Menu lateral | título, etiqueta, botões, item ativo, grupos |
| Painel de configuração | campos, dicas, botões, faixa de aviso, foco do teclado visível (Tab) |
| Grafo de tags | nós, ligações, nós esmaecidos na busca, legibilidade dos nomes |
| Quadro | colunas, cartões, status |
| Post-its | cor de cada post-it continua legível (não muda com a paleta) |
| Bloco de código | continua escuro e legível; links de citação (`pasta/arquivo.md`) legíveis |
